AI-Powered Alternate Credit Scoring (FinTech)
Traditional credit scoring (CIBIL-style) excludes people with no formal credit history — gig
workers, students, new-to-credit individuals. Build an AI model that scores creditworthiness
using alternate data (utility bill payments, mobile recharge regularity, transaction behavior,
digital footprint, etc.) instead of/along with traditional bureau data.
MVP Scope for 10 Hours (Keep it Lean)

Input: A synthetic/alternate dataset (utility payments, spending patterns, income
proxies, digital behavior signals)
Model: A classification model predicting a credit score/band (e.g.,
Low/Medium/High risk) — logistic regression, Random Forest, or XGBoost (don't
overengineer; a well-tuned simple model beats a broken complex one)
Explainability layer: Use SHAP or feature-importance to show why someone got a
score (huge differentiator for judges —
"alternate scoring must be explainable, not a
black box")
Frontend: Simple form/dashboard — user enters alt-data inputs → get score +
explanation + risk band
Bonus (if time permits): LLM-generated natural-language explanation of the score
("Why was I scored this way?") using any LLM API
Suggested Deliverables Checklist
[ ] Cleaned/prepared dataset (or synthetic data generator script)
[ ] Trained model + evaluation metrics (accuracy, F1, AUC-ROC)
[ ] Explainability visualization (SHAP values/feature importance chart)
[ ] Simple web UI to input data and view score
[ ] 1-pager on real-world feasibility (RBI/NBFC context, data privacy angle)
