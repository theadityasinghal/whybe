# Whybe - AI-Powered Alternate Credit Scoring

Traditional credit scoring (CIBIL-style) excludes people with no formal credit history — gig workers, students, and new-to-credit individuals. 

**Whybe** builds an AI model that scores creditworthiness using alternate data (utility bill payments, mobile recharge regularity, transaction behavior, digital footprint, etc.) instead of or alongside traditional bureau data, complete with an explainability layer (SHAP) and an intuitive web interface.

## Project Structure
- `datasets/`: Alternate credit datasets and credit score classification data.
- `ps.txt`: Problem statement and project roadmap.
